# 论文计划 / Paper plan

工作草稿。所有数字都必须来自可复现的实验运行（`~/.ctxport/distilled/run-*.json` 或 `benchmarks/`），不写未测量的结论。

## 暂定题目 / Working titles

- **Portable Memory: Lossless, Coverage-Guaranteed Migration of Personal Context Across LLM Assistants**
- 可携带的记忆：跨大模型助手的无损、可验证覆盖的个人上下文迁移

## 要回答的问题 / Research questions

- **RQ1 获取**：不依赖平台配合，能否从主流助手（ChatGPT、Claude、Codex、Gemini 等）无损取回用户的全部历史？各平台把数据存在哪里、以什么形式？
- **RQ2 提炼**：在给定长度预算下，哪种方法能保留最多的用户事实、编造最少？分层提炼 vs. 让旧助手“总结你对我的了解” vs. 一次性平铺总结 vs. 规则抽取。
- **RQ3 效用**：把迁移后的记忆交给一个全新的助手，它对用户相关问题的回答准确率提升多少？完整档案 vs. 精简版 vs. 检索（MCP）。
- **RQ4 成本与隐私**：每种方法的 token、时间成本；全本地流程能做到什么程度。

## 贡献 / Contributions (draft)

1. 一个统一、无损的对话数据模型和开源工具（ctxport），覆盖 9 个平台；对每个平台的真实存储格式做了测量与记录（例：某版 Codex 中 93% 的线程只存在 SQLite，rollout 文件已被清理）。
2. **覆盖可验证的分层记忆提炼（CHMD）**：L1 情节卡（带证据消息编号）→ L2 规范事实（每个 L1 事实恰好被一个 L2 事实覆盖，代码校验）→ L3 主题档案（每个 L2 事实至少出现一次，代码校验）→ L4 按目标预算渲染。模型漏掉的内容由程序补回，因此完整档案的覆盖率按构造为 100%；准确性（不编造）单独评估。
3. 一个评测协议：覆盖率–长度曲线、事实准确率、下游探针问答准确率、成本。
4. 模型无关：任何 OpenAI 兼容接口或“手动模式”（把提示词贴进任意聊天 AI），方便复现与比较不同模型。

## 方法细节（与代码对应）/ Method ↔ code

| 层 | 代码 | 关键保证 |
|---|---|---|
| L0 输入 | `distill.conversation_input` | 只发用户消息 + 截断的助手回答；代码/日志剔除；密钥遮蔽 |
| L1 情节卡 | `distill.build_cards` | 每条事实带证据编号；按内容哈希缓存，增量处理 |
| L2 规范事实 | `distill.premerge` + `merge_facts` | 覆盖不变量 `⋃covers = L1 ids`（`assert`）；模型漏掉的原样补回（计数 `l2_restored`） |
| L3 档案 | `distill.write_document` | 每个 L2 id 至少出现一次；遗漏补写（计数 `l3_appended`）；删除编造的 id |
| L4 渲染 | `distill.render_budget` | 按重要度（出现次数、是否用户确认、新近度）选取；报告 coverage@budget |

## 实验 / Experiments

### E1 获取保真度（RQ1）
- 对每个平台：源数据 → 库 → 导出，逐条精确比对（已有 3 个样本的脚本，扩展到全部对话或分层抽样）。
- 报告：对话数、消息数、分支数、注入内容识别率、失败/警告率。

### E2 提炼质量（RQ2）
- 基线：B1 让旧助手自述（真实的“总结一下你对我的了解”提示）；B2 规则抽取；B3 单次平铺总结（同一模型、同一预算）；本方法 CHMD；消融：去掉 L2 合并 / 去掉 L3 / 去掉覆盖补回。
- 金标准：从用户消息中人工标注原子事实（抽样 N 个对话，两人标注，算一致性）。
- 指标：
  - 覆盖率（召回）= 被输出蕴含的金标准事实比例（人工 + LLM 评委，报告二者一致性）
  - 精确率 = 输出中有原文依据的陈述比例（编造率 = 1 − 精确率）
  - 覆盖率–长度曲线（500 / 1500 / 4000 / 12000 / 不限字）
- 多个模型（不同服务商、不同规模）各跑一遍，看方法是否稳健。

### E3 下游效用（RQ3）
- 从金标准事实生成探针问题（“我在用什么编辑器？”“我的项目用什么框架？”），留出不参与提炼的部分做干扰检查。
- 条件：无记忆 / B1 / 精简版 / 完整档案 / 完整档案 + MCP 检索。
- 指标：探针准确率；对无关问题不过度使用记忆（误用率）。

### E4 成本（RQ4）
- 每种方法的调用次数、输入/输出 token、耗时（run 日志已记录）；增量更新的边际成本。

## 数据与伦理 / Data & ethics

- 论文只报告汇总数字，不公开任何真实对话；作者本人数据仅用于可行性演示。
- 主实验用：合成用户（脚本生成的多平台历史，带金标准事实）+ 知情同意的志愿者（本地运行、只回传指标）。涉及人类受试者前确认学校是否需要伦理审批。
- 浏览器扩展使用网站前端非公开接口：讨论平台条款、只取本人数据、限速与退避。
- 作者贡献如实说明：包括合作者的贡献，以及代码在 AI 辅助下完成。
