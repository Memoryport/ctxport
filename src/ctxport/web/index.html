用你自己选的模型，把所有对话分层提炼成一份完整档案：每个对话一张“情节卡”，合并去重，再写成按主题分组的档案。程序会检查每一条事实都被写进去（覆盖率），生成后上面各处的“一键导入”都会改用这份档案。

编程 Agent

  
把已确认的记忆写进它们的指令文件。只改 ctxport 自己那一块，你原来写的内容不动，第一次写入前自动备份。

  


  
给 Agent 接上 MCP

  
接上之后，这些工具可以随时搜索你在所有 AI 里的全部历史对话，而不只是一份摘要。

  


  
网页版 AI 的记忆

  
通过 ctxport 浏览器扩展，在你已登录的网页里直接写入；没有装扩展时，会复制文本并打开对应页面让你粘贴。

  


  
桌面聊天应用

  
生成导入文件、在访达里定位并打开应用。ctxport 不会直接改动这些应用的数据库。
