完整记忆档案

用你已有的 AI（Claude Code、Codex、ChatGPT / Claude 网页版等），把所有对话分层提炼成一份完整档案：每个对话一张“情节卡”，合并去重，再写成按主题分组的档案。程序会检查每一条事实都被写进去（覆盖率），生成后上面各处的“一键导入”都会改用这份档案。

网页版 AI：逐批复制粘贴

    
1. 复制第一批，粘贴到 ChatGPT 或 Claude 网页的新对话；2. 把它回复的 JSON 整段复制回下面的框；3. 点“提交这一批”，再做下一批。全部提交后点上面的“导入结果并生成档案”。

    

      

    
    

  


  
ChatGPT 官方导出

  
ChatGPT 对单个对话的读取有限速，对话很多时扩展同步会很慢。官方导出一次拿到全部：ChatGPT 把下载链接发到你的邮箱，下载后 ctxport 会自动认出“下载”文件夹里的导出包并导入，与扩展已同步的部分自动去重。

  

    
ChatGPT需要浏览器扩展

      
在你已登录的 ChatGPT 页面里替你点“导出数据”。

      

    
下载文件夹ChatGPT / Claude.ai

      
下载好官方导出 zip 后点这里，或下次同步时会自动导入。

      

  


  
编程 Agent

  
把已确认的记忆写进它们的指令文件。只改 ctxport 自己那一块，你原来写的内容不动，第一次写入前自动备份。

  


  
给 Agent 接上 MCP

  
接上之后，这些工具可以随时搜索你在所有 AI 里的全部历史对话，而不只是一份摘要。

  


  
网页版 AI 的记忆

  
通过 ctxport 浏览器扩展，在你已登录的网页里直接写入；没有装扩展时，会复制文本并打开对应页面让你粘贴。

  


  
桌面聊天应用

  
生成导入文件、在访达里定位并打开应用。ctxport 不会直接改动这些应用的数据库。
