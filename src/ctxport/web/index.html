第一次用？ctxport 在做什么
1 收集把 ChatGPT、Claude、Codex 等的聊天记录汇总到这台电脑上的一个数据库里。全程在本机，不上传。
2 提炼让你自己的 AI（比如 Claude Code）把所有对话读一遍，写成一份“关于你”的档案：身份、项目、偏好、习惯。
3 导入把这份档案一键写进别的 AI：Claude Code、Codex、Cursor、ChatGPT、Claude 网页版……换 AI 不用从头介绍自己。
1

收集聊天记录

本机上的 Claude Code、Codex、Cherry Studio、Chatbox 等会自动读取；网页版的 ChatGPT 和 Claude 需要用官方导出。

–对话
–消息
–来源

网页版 AI：用官方导出

导出包下载到“下载”文件夹后点一下就能导入；重复导入会自动去重，不会多出对话。

ChatGPT官方导出
  1. 点“发起导出”（装了扩展会替你点；没装就打开设置页，你点“导出数据”）
  2. 几分钟到一天内，ChatGPT 会把下载链接发到你的邮箱
  3. 下载 zip（不用解压），回来点“检查下载文件夹”
Claude.ai官方导出
  1. 点“打开导出页面”，在 Claude 设置 → 隐私 里点“导出数据”
  2. 邮件里下载 zip 到“下载”文件夹
  3. 回来点“检查下载文件夹”
浏览器扩展同步的记录（不用扩展可以跳过）

扩展会一条条读回网页上的对话，比较慢。改用官方导出后，可以在这里删掉扩展收集的部分并停止同步；官方导出的对话和你确认过的记忆都会保留。

2

提炼记忆档案

用你已经在用的 AI 读每一个对话、写一张“情节卡”；ctxport 在本机把卡片合并去重，写成一份按主题分组的档案，并检查每条事实都写进去了。不需要 API Key。

这台电脑上没有找到 Claude Code 或 Codex（包括 ChatGPT 桌面应用自带的 Codex）。可以安装后重新打开 ctxport，或者改用“网页版 AI”。
写情节卡主要是把事实摘出来，中等模型通常就够了。
越高越仔细，也越慢、越耗额度。推荐 low；对话很杂乱时可以试 medium。
已经写过卡片、内容也没变的对话会自动跳过，所以可以先试一小批，满意了再扩大范围。
几批同时处理，速度大约快几倍，额度消耗总量不变。开太多会撞上服务商的速率限制、也更吃电脑内存，一般 4–8 就够。
都不勾时会暂停，已写好的卡片都保留。等待期间电脑会保持不睡眠，ctxport 要一直开着；点“停止”可以取消等待。
计算中…
  1. 选择范围，点“准备批次”
  2. 点“复制这一批”，粘贴到 ChatGPT 或 Claude 网页的新对话里发送
  3. 把 AI 回复的整段 JSON 复制回下面的框，点“提交这一批”；再做下一批
  4. 全部提交后，点右边的“生成档案”
  1. 点“打开任务文件夹”，ctxport 会把待处理的对话和说明（TASK.md）放进去
  2. 在任意 Agent（Cursor、Windsurf、Gemini CLI……）里打开这个文件夹，对它说：
    “按 TASK.md 处理 conversations/ 里还没有卡片的文件”
  3. 它写完 cards/ 之后，回来点右边的“生成档案”

检查和修改 

        
导入前看一眼，删掉不对或不想让别的 AI 知道的内容。

      

      

        
记忆档案–

          
第 2 步生成的档案，分精简、标准、完整三个版本；第 4 步导入的是你选的那个版本（ChatGPT 有 1400 字上限，始终用最短的版本）。

          

        
单条记忆– 已确认 · – 待审核

          
从聊天里自动摘出的短句（比如“用户偏好简洁回答”）。只有“已确认”的会被导入；没有档案时就导入这些。

          

      

    


    
    

      
4

        
导入到其他 AI 

        
选你在用的 AI，点一下。之后档案更新了，回来再点一次“更新”即可。

      

      

        

          

          

      

      
编程 Agent

      
写进它们的指令文件（如 ~/.claude/CLAUDE.md）。只改 ctxport 自己那一块，你原来写的内容不动，第一次写入前自动备份。

      

      
让 Agent 能搜索全部历史（MCP）

      
档案是摘要；接上 MCP 后，Agent 遇到需要时还能搜你在所有 AI 里的原始对话。连接后需要重启对应的应用。

      

      
网页版 AI

      
装了 ctxport 浏览器扩展会直接写进去；没装时会复制好文本并打开对应页面，你粘贴保存即可。

      

      
桌面聊天应用

      
生成导入文件并在访达里定位。ctxport 不会直接改这些应用的数据库。
